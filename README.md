# DeliGeli — Picolés com fruta de verdade

Uma experiência visual interativa desenvolvida para apresentar a linha de picolés DeliGeli. O projeto combina design moderno, animações e transições suaves para destacar cada sabor de maneira dinâmica e envolvente.

Acesse o site: https://apresentacao-picoles.netlify.app

##  Sabores

- 🫐 Amora
- 🥝 Kiwi
- 🍌 Banana
- 🍓 Morango

## Funcionalidades

- Apresentação individual de cada sabor.
- Navegação interativa entre os produtos.
- Animações e transições suaves.
- Elementos visuais com movimento contínuo.
- Layout responsivo para diferentes dispositivos.
- Interface moderna com foco na experiência visual.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

##  Identidade visual

O projeto utiliza uma identidade visual colorida e divertida, com tipografia personalizada, imagens dos produtos e fundos que acompanham a apresentação de cada sabor.

##  Objetivo

Explorar técnicas de desenvolvimento Front-End, animações web e criação de experiências digitais para apresentação de produtos.
